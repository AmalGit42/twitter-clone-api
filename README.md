# Twitter Clone - REST API

A REST API for a Twitter-like application, built with Node.js, Express.js and SQLite.

## Features
- User registration and login with JWT authentication
- Middleware to protect routes (401 for invalid or missing token)
- Tweet feed of people the user follows
- Following and followers lists
- Tweet details with likes count, replies count and date-time
- List of users who liked a tweet and replies on a tweet
- Create and delete your own tweets
- 11 API endpoints in total

## Tech Stack
Node.js, Express.js, SQLite, JWT

## Run locally
1. Clone the repo
2. `npm install`
3. `node app.js`
